# Evaluating-the-results-of-A-B-testing-of-a-product-feature
На образовательной платформе запустили эксперимент: одной части пользователей добавили систему достижений, которая отмечает тех, кто решает задачи изо дня в день. Нужно понять, сработала ли эта затея, опираясь на цифры, и выбрать один из вариантов — включить функцию для всех или свернуть.
